# 1С сатылым талдау боты

Telegram-бот. Оған 1С-тің **«Валовая прибыль по клиентам»** есебін PDF етіп жібересіз, ол бірден есептеп айтады:

- сатылым, заказ саны, орташа чек, медиана, плитка м² және орташа бағасы;
- **не сатылды** — тауар топтары, плитка форматтары, ең көп сатылған позициялар, ең жиі алынатындар;
- **қай жерде** — LI22 / XL22 сериялары, бонус санаттары (1–5-санат), менеджерлер;
- ең ірі заказдар, сатылымның шоғырлануы, заказ көлемі;
- **пайда** — 1С-та «Себестоимость» / «Валовая прибыль» бағандары болса: топ, санат, формат, тауар, заказ бойынша пайда мен маржа, шығынмен сатылған жолдар; бағандар болмаса — жеңілдік қайда кеткені;
- апта күндері мен сағаттар, назар аударатын жайттар (қайтару, арзан сатылған қалдық, жеткізу т.б.);
- **алдыңғы есеппен салыстыру** — келесі айдың есебін жібергенде өзгерістерді көрсетеді.

Соңында толық есепті дашборд түріндегі **HTML файл** етіп жібереді — телефонда да, компьютерде де ашылады.

---

## Қазір қай жерде тұр

Бот **Render**-де, тегін web service ретінде жұмыс істейді:

- сервис: `ceramo-sales-bot` (Франкфурт, тегін жоспар, Docker);
- код: GitHub `orken2026/ceramo-stock` репозиторийінің **`sales-bot`** тармағы (негізгі `main` тармағына тиіспейді);
- `sales-bot` тармағына жаңа код жіберсеңіз, Render өзі қайта жинап іске қосады.

**Тегін серверді білу керек:**

- 15 минут ешкім жазбаса, сервер «ұйықтайды». Келесі бірінші хабарға жауап **1 минутқа дейін** кешігуі мүмкін — бұл қалыпты.
- Сервердің дискісі әр қайта іске қосылғанда тазарады. Сондықтан рұқсаттар тізімі мен есептер тарихы **иесінің Telegram чатындағы бекітілген `satylym-bot-zhady.json` файлында** сақталады. Оны өшірмеңіз және бекітуден алмаңыз.

**Render айнымалылары (Environment):**

| Айнымалы | Не үшін |
|---|---|
| `BOT_TOKEN` | @BotFather берген токен |
| `ADMIN_IDS` | иесінің Telegram ID-і (бірнешеу болса үтірмен) |
| `OWNER_CODE` | иесі болуға арналған құпия код: `https://t.me/<бот_логині>?start=<OWNER_CODE>` |

`ADMIN_IDS` бос кезде бот иесін тек құпия сілтеме арқылы қабылдайды (`OWNER_CODE` болмаса — бірінші `/start` жазған адамды). `ADMIN_IDS` жазылған соң құпия код жұмыс істемейді.

Сервердің күйін тексеру: `https://ceramo-sales-bot.onrender.com/healthz`.

## Рұқсат беру

Бот жабық: тек иесі және ол рұқсат берген адамдар қолдана алады.

| Команда | Не істейді |
|---|---|
| `/allow 123456789 Аты` | рұқсат беру (ID — адамның Telegram ID-і) |
| `/deny 123456789` | рұқсатты алу |
| `/users` | рұқсаты бар адамдар |
| `/myid` | өз ID-іңізді көру |
| `/history` | сақталған есептер (салыстыру үшін) |

Бөтен адам `/start` жазса, бот оның ID-ін иесіне жібереді — `/allow ID` деп жазсаңыз болды.

## Есепті 1С-тан қалай шығару

1. 1С-та «Валовая прибыль по клиентам» есебін ашыңыз, кезең мен менеджерді таңдаңыз.
2. Тауар бойынша талдау үшін топтау: **Менеджер → Заказ клиента → Сегмент → Номенклатура**. (Тек заказдар бойынша есеп те оқылады, бірақ онда «не сатылды» бөлімі болмайды.)
3. Пайданы көру үшін «Настройки» ішіндегі «Показатели» (немесе «Поля») бөлімінен **Себестоимость** және **Валовая прибыль** белгілеңіз. Бот бағандарды тақырыбы бойынша өзі табады.
4. «Сформировать» → «Сохранить как» (немесе Печать) → **PDF** → ботқа жіберіңіз.

## Баптау

- `salesreport/analysis.py`: `CLEARANCE_PRICE = 1500` (осыдан арзан плитка «қалдық» деп белгіленеді, ₸/м²), `BIG_ORDER = 100000` (ірі заказ шегі).
- `salesreport/classify.py`: тауар топтарын анықтайтын сөздер. Жаңа тауар түрі «Басқа тауарлар» болып шықса, осында қосыңыз.

## Басқа жерде іске қосу (қажет болса)

Бір токенмен бот тек бір жерде жұмыс істеуі керек: компьютерде іске қоссаңыз, Render-дегі webhook өшіріледі.

- **Windows компьютері:** Python 3.11+ орнатыңыз («Add python.exe to PATH»), `run_bot.bat` басыңыз, ашылған `.env` файлына `BOT_TOKEN` жазыңыз. Терезе ашық тұрғанда бот жұмыс істейді (polling режимі).
- **Docker бар сервер:** `.env` жасап, `docker compose up -d`.

## Тексеру

```bash
python analyze_pdf.py есеп.pdf                 # мәтінді экранға шығарады, жанына HTML сақтайды
python tests/test_bot_offline.py есеп.pdf      # ботты Telegram-сыз толық тексеру (webhook, жады, рұқсаттар)
```

(`tests/make_synthetic_pdf.py` тест PDF жасау үшін `reportlab` керек: `pip install reportlab`.)

PDF файлдар сақталмайды — өңделгеннен кейін бірден өшіріледі.
