# Қойма қалдығы: Telegram Mini App

Артикул немесе тауар атауын жазасыз, бот 1С-тен қай қоймада қанша қалғанын көрсетеді.
Қолданба 1С-ке тек оқу сұраныстарын жібереді, ештеңе өзгертпейді.

## Қалай жұмыс істейді

```
Telegram → сіздің сервер (осы жоба) → 1С OData
```

- 1С логині мен құпиясөзі тек серверде тұрады, телефонға жетпейді.
- Әр сұраныстың Telegram-нан келгені қолтаңба арқылы тексеріледі.
- Mini App-ты тек рұқсат берілген Telegram ID-лер ашады. Рұқсатты тек әкімші береді.

## 1. Ботты ашу

1. Telegram-да @BotFather → `/newbot` → токенді көшіріңіз.
2. @userinfobot арқылы өз Telegram ID-іңізді біліңіз.

Токен мен құпиясөзді чатқа немесе кодқа жазбаңыз, тек `.env` файлына немесе хостинг баптауына енгізіңіз.

## 2. 1С-те бөлек пайдаланушы ашу

1. Жаңа пайдаланушы ашыңыз, логин латынша болсын, мысалы `tg_bot`.
2. «Аутентификация 1С:Предприятия» қосулы болсын, күшті құпиясөз қойыңыз.
3. Құқықты тек оқуға беріңіз: `Номенклатура`, `Склады`, өлшем бірліктері, `ТоварыНаСкладах`.
4. Бұл пайдаланушыға барлық қоймаларды көруге рұқсат беріңіз. Қолданба 1С-ке `allowedOnly=true`
   белгісімен сұраныс жібереді, сондықтан рұқсат жоқ қойманың қалдығы қатесіз, үнсіз түсіп қалады
   және жалпы сан кем шығады.

Бас бухгалтердің немесе әкімшінің логинін қолданбаңыз.

## 3. Атауларды тексеру

Python 3.12 керек.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # Windows: copy .env.example .env
```

`.env` файлын толтырып, 1С-ке қолжетімді компьютерде іске қосыңыз:

```bash
python check_1c.py               # қосылу мен өріс атаулары
python check_1c.py CS-6060       # нақты артикулмен толық тексеру
```

Бірінші команда тек өріс атауларын шығарады, сан да, клиент те көрсетілмейді.
`[ҚАТЕ]` шықса, дұрыс атауды `.env` ішіндегі `ONEC_...` жолдарына жазыңыз немесе шығысты маған жіберіңіз.

## 4. Серверге қою

Telegram Mini App-қа `https` мекенжайы керек. Сервер 1С-ке жете алуы тиіс.

**1С интернеттен ашылса (хостинг):** жобаны GitHub-қа салып, Render-де Blueprint ретінде ашыңыз
(`render.yaml` дайын) немесе `Dockerfile` арқылы кез келген хостингке қойыңыз.
Баптауларға `.env` мәндерін енгізіңіз. `PUBLIC_URL` сервер мекенжайы болады.

**1С тек кеңсе желісінде болса:** жобаны сол желідегі үнемі қосулы компьютерде іске қосып,
Cloudflare Tunnel арқылы https мекенжай алыңыз. Бұл жолда 1С интернетке ашылмайды.

```bash
uvicorn --factory app.main:build_app --host 127.0.0.1 --port 8000
```

Сервер іске қосылғанда webhook пен мәзір батырмасы өздігінен тіркеледі.

Рұқсат тізімі әкімшінің ботпен чатындағы бекітілген хабарда сақталады, сондықтан ақысыз хостингте де
өшпейді. Ол хабарды өшірмеңіз: өшірілсе, тек әкімші мен `ALLOWED_TELEGRAM_IDS` ішіндегілер кіре алады.

Ақысыз Render тарифінде сервер ұзақ қолданылмаса ұйықтайды, келесі ашылуы бір минутқа дейін созылуы мүмкін.

## 5. Қолдану

Қызметкер ботқа `/start` жазады. Рұқсаты жоқ болса, бот оған Telegram ID-ін көрсетеді.
Ол ID-ні сізге жібереді, сіз ботта рұқсат бересіз:

| Команда | Әрекеті |
|---|---|
| `/add 123456` | Рұқсат беру |
| `/remove 123456` | Рұқсатты алу |
| `/users` | Рұқсаты бар адамдар |

Бұл командаларды тек `ADMIN_TELEGRAM_ID` орындай алады.

## Тексерістер

```bash
pip install pytest pytest-asyncio
pytest
```

Тесттер `tests/fake_1c.py` ішіндегі жалған 1С серверімен жүреді, нақты 1С-ке қосылмайды.
